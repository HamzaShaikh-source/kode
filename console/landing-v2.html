From brief to merged code, without sharing prompts by hand.

PlanA model drafts tasks with disjoint files and a frozen interface contract. You review it.
AssignWork is split by weight so everyone gets a similar share and a minimum number of commits.
BuildEach laptop clones, branches and runs its own agent. Commits are pushed with that laptop's own GitHub login.
MergeEdits outside a task's files are reverted by code. Pull requests merge in dependency order.
Verify and fixThe test command runs on the merged result. Failures become fix tasks for the right owner.

A real run: three laptops, nine tasks, a private GitHub repository, 70 passing tests, with commits from all three teammates.

The lead has full access. Teammates keep the kill switch.

Joining with an invite grants the access you chose, and the lead can watch or type into any session. A teammate can pull the kill switch at any time.

  • Full access is the default for new invites.
  • Kill switch on each laptop drops every session to watch-only.
  • Audit log records pairing, starts and everything typed by the lead.
  • Secrets are redacted on the teammate's machine before output leaves it.

One orchestrator to coordinate the rest.

Give it a goal in plain language. It lists the team, reads screens, starts sessions and sends tasks, and asks you before every write.

  • Three autonomy levels: observe, ask, or auto where consent already exists.
  • Hard budgets: 12 steps, 15 minutes, 150k tokens per run.
  • Terminal text is untrusted. It is never followed as an instruction.

Bring your own endpoint.

Save a base URL, key and protocol once. Start any compatible agent through it, per session, without touching its global config.
